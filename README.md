# RCS Journal

Modern academic journal publishing platform.

## Phase 2 starter

This repository currently contains the public-facing frontend foundation with placeholder data.

### Stack
- Next.js
- TypeScript
- React
- CSS
- Lucide-ready dependency

### Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Important
This is the first implementation phase. Authentication, MySQL/Prisma, manuscript workflows, reviewer/editor portals, DOI integration, file storage, email and admin systems are intentionally not connected yet.

The reference website IJOASAR is used for functional/information-architecture inspiration. Content, branding and implementation are original placeholders and should be replaced with client-approved material.
